## Overview

**Perplexity AI, Inc.** adalah perusahaan swasta asal Amerika Serikat yang menawarkan mesin pencari web berbasis AI. Berbeda dengan mesin pencari tradisional, Perplexity AI memproses query pengguna dan mensintesis respons menggunakan large language models (LLM) dengan kemampuan real-time web search.

## Products & Services

### 1. Search Engine (Core Product)
Mesin pencari utama yang menggunakan LLM untuk menghasilkan respons dengan mengutip sumber dari internet secara real-time.

### 2. Perplexity Pro
Langganan premium dengan fitur:
- Model AI yang lebih canggih (GPT-5.5, Claude Opus 4.7, Gemini 3.1 Pro, Kimi K2.6)
- Keamanan dan perlindungan data yang lebih baik
- Upload dokumen untuk pencarian
- Akses API programmatic

### 3. Perplexity Assistant
AI assistant multifungsi yang dapat:
- Menjalankan tugas lintas aplikasi (hailing rides, mencari lagu)
- Menggunakan kamera untuk menjawab pertanyaan tentang lingkungan
- Menjawab pertanyaan tentang konten di layar

### 4. Perplexity Comet
Browser AI berbasis Chromium:
- Diluncurkan Juli 2025 (premium)
- Dirilis gratis Oktober 2025
- Integrasi mesin pencari Perplexity
- Mampu membuat ringkasan artikel, mendeskripsikan gambar, menulis email

### 5. Sonar API
Layanan API pencarian berbasis Meta's Llama model untuk pengembang AI.

### 6. Shopping Hub
Platform belanja dengan rekomendasi produk AI yang didukung oleh Amazon dan Nvidia.

### 7. Finance Tools
Fitur keuangan termasuk:
- Pelacak harga saham real-time
- Perbandingan peer perusahaan
- Analisis keuangan dasar

### 8. Internal Knowledge Search
Untuk pengguna Pro/Enterprise:
- Browsing web dan dokumen internal secara bersamaan
- Upload dan pencarian file (Excel, Word, PDF)
- Enterprise Pro: upload dan indexing hingga 500 file

## Controversies

### 1. Copyright & Trademark Infringement
- **Forbes** (Juni 2024) - Menuduh Perplexity menyalin konten tanpa atribusi
- **The New York Times** (Oktober 2024) - Mengirim cease-and-desist
- **Dow Jones & New York Post** (Juni 2024) - Gugatan copyright dengan tuduhan hallucinated quotes
- **BBC** (Juni 2025) - Ancaman tindakan hukum untuk content scraping
- **Yomiuri Shimbun** (Agustus 2025) - Gugatan terkait 120.000 artikel
- **Asahi Shimbun & Nikkei** (September 2025) - Gugatan copyright
- **Reddit** (Oktober 2025) - Gugatan atas data scraping

### 2. Trademark Dispute
- Perplexity Solved Solutions (PSS) menggugat atas penggunaan nama "Perplexity"

### 3. Stealth Web Crawlers
- **Wired** (Juni 2024) - Menemukan Perplexity tidak menghormati robots.txt
- **Cloudflare** (Agustus 2025) - Menemukan penggunaan stealth web crawlers
- CEO Cloudflare, Matthew Prince, menyatakan Perplexity "acts more like North Korean hackers"

## How It Works

### Search Flow
1. User enters query
2. System performs real-time web search
3. LLM synthesizes information from multiple sources
4. Response includes citations to original sources
5. User can follow up with contextual questions

### Modes
- **Auto**: Default mode, otomatis memilih model terbaik
- **Pro**: Enhanced mode dengan model premium
- **Reasoning**: Step-by-step reasoning untuk masalah kompleks
- **Deep Research**: Penelitian mendalam dengan waktu lebih lama
